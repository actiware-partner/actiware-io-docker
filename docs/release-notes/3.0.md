# Release 3.0

_Veröffentlicht: 11.07.2025_ · _Zielgruppe: Administratoren und Betreiber_

Erste versionierte Docker-Umgebung für ACTIWARE.IO 3: Infrastruktur, Services, Module und ein vorgeschalteter Proxy lassen sich mit Docker Compose gemeinsam starten.

## Sicherheitshinweise

> ⚠️ **Sicherheitsrelevant:** Die Vorlage `.env` enthält für `TOKEN_MASTER`, die Datenbank-Zugangsdaten und die MinIO-Schlüssel keine vorbelegten Werte mehr. Diese Werte müssen bei der Einrichtung selbst gesetzt werden.

> ⚠️ **Sicherheitsrelevant:** Weiterhin vorbelegt sind die Standardanmeldung (`AUTH_DEFAULT_USER`/`AUTH_DEFAULT_PASS`), das Web-Client-Secret, die RabbitMQ-Zugangsdaten und `PROCESS_TRIGGER_TOKEN`. Ändern Sie diese Werte vor dem produktiven Betrieb.

## Features

- Docker-Compose-Umgebung für ACTIWARE.IO 3, aufgeteilt in Infrastruktur (`backend.docker-compose.yml`: PostgreSQL, RabbitMQ, Solr, MinIO), Services (`services.docker-compose.yml`) und Module (`module.docker-compose.yml`)
- Apache-Proxy als zentraler Einstiegspunkt mit fertigen Konfigurationen für HTTP und HTTPS
- Identity Service ersetzt den bisherigen Auth Service, inklusive eigenem Web-Client (`AUTH_DEFAULT_WEB_CLIENT_ID`, `AUTH_DEFAULT_WEB_CLIENT_SECRET`)
- Deutschsprachige Administratoren-Dokumentation mit Anleitungen zur Einrichtung, zur HTTPS-Umstellung und zur Passwortverwaltung

## Improvements

- Container-Images verwenden standardmäßig die jeweils aktuelle Version ihrer Hauptversion (`*-latest`) statt fester Vorabversionen
- PostgreSQL 17 als Standardversion
- Bereinigte `.env`-Vorlage ohne installationsspezifische Beispielwerte (Servername, SAP- und Solr-Vorgaben)
